# Math Garden: learning improvements

The user approved all eight recommendations in the educator review. Implement them together while preserving the eight activity cards, existing saved rewards, keyboard access, untimed play, and a dependency-free offline build.

## Teaching design

- Accept a square as a rectangle; vary valid triangle proportions and shape orientation from the beginning.
- Track individual skills, with independent, supported, and demonstrated outcomes. Four independent answers among the latest five, using at least three distinct questions, can extend the number range. A successful check on a later day provides separate retention evidence; this is practice guidance, not a standardized assessment. Do not lower unrelated skills after a mistake.
- Schedule a same-skill follow-up after a worked example and revisit previously practiced skills on later days. Preserve free activity selection. Parent Corner can launch a particular skill.
- Teach counting from one, seeing five and extra ones, counting on from the larger addend, and recognizing a full ten. All help remains available without penalty to rewards.
- Missing-part hints distinguish the known part and count the missing part. Building hints explain how many to add/remove without filling the answer immediately.
- Add collect-an-exact-quantity, two decompositions of a number, conservation after rearrangement, and small-group recognition with optional reveal.
- Include zero and empty groups from the start; vary equation orientation; explicitly regroup twenty as two tens and zero leftover ones.
- Patterns include extension, selecting the repeating unit, repairing a mistake, and constructing a personal pattern repeated three times.
- Feedback describes only visible work. A corrected answer earns a star; finishing a round still earns a star and sticker. Parent Corner reports skill-specific evidence and a matching physical activity.

## Boundaries

Use the existing mathgarden.v1 key and preserve historical activity totals. New skill records start without assuming mastery from legacy aggregate levels. No voice recording, external model, analytics, new runtime package, or automatic production deployment. A new feature branch and draft PR provide review before integration.
