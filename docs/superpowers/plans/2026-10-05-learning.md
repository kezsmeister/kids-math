# Math Garden Learning Implementation Plan

> Execute inline with superpowers:executing-plans and test-driven-development. The user's instruction to apply all recommendations authorizes implementation.

**Goal:** Implement every recommendation in the educator review.
**Architecture:** A curriculum catalog and evidence store select a skill and difficulty before existing activity generators run. Shared assistance tracking records supported work. New constructive tasks use native controls and the same question-owned timers.
**Tech Stack:** Existing HTML/CSS/classic JavaScript, Node tests and jsdom.
**Spec:** docs/superpowers/specs/2026-10-05-learning-design.md

## Global constraints
- Preserve existing rewards and activity totals under mathgarden.v1.
- No runtime dependencies, recordings, backend, timed answers, or automatic merge.
- Help is available throughout; supported success is distinguished from independent evidence.

## Review focus
- A late hint cannot change the next question or classify its answer as supported.
- A worked example leads to a fresh solvable question on the same skill.
- Equivalent geometric/quantity answers are accepted; unsupported claims of a strategy are avoided.
- Old and malformed saves retain valid data without creating false mastery.
- New construction tasks work on small touch screens and with a keyboard.
